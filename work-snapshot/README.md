# גיבוי עבודת איסוף הספקים

צילום מצב של סביבת העבודה המקומית, שנשמר בענף נפרד לפי בקשת המשתמש. הענף והקבצים בו פומביים. הגיבוי כולל פרטי קשר ומזהים שפורסמו בקובצי המקור, וקובצי חילוץ שטרם אומתו.

- `sources/` — קובצי המקור המקומיים שסופקו.
- `consultant_app/` — אב הטיפוס, סקריפטי החילוץ והקליטה, נתוני הבדיקה, הדוחות והבדיקות.
- `consultant_app/staging/review-enriched-v3.sqlite3` — מסד הבדיקה הכולל 1,150 שורות מ־19 מקורות; אלה שורות מקור ולא בהכרח ספקים ייחודיים.
- `consultant_app/staging/catalog-import-review-v4.json` ו־`catalog-import-review-v6.sql` — חבילת הקליטה האחרונה שהוכנה ל־311 רשומות; הסקריפט לא הופעל על המסד החי. האולמות והגרסאות ההיסטוריות נשמרו בנפרד.
- `consultant_app/staging/historical/` — גרסאות קודמות לחינוך ולתחבורה, לבדיקת התאמה וכפילויות לפני כל קליטה.
- `consultant_app/patches/` — תיקון תצוגה מוצע. השינוי הועלה גם בבקשת שינוי #30 ומצב המיזוג שלו צריך להיבדק בנפרד.
- `SHA256SUMS` — טביעות קבצים לצורך בדיקת שלמות הגיבוי.

הסביבה אינה כוללת תיקיות התקנת חבילות, סביבות פייתון או קובצי מטמון שניתנים ליצירה מחדש. אין לראות בנתונים אישור להתקשרות או הוכחה לתוקף מאגר.

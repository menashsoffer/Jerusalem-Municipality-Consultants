# מאגרי יועצים – גרסת התחלה

אב טיפוס מקומי לחיפוש בפרסומי מאגרים. המערכת כוללת עשרה פרסומים ראשונים בלבד, ואינה כוללת עדיין נתוני ספקים, אימות תוקף או הזדהות ארגונית. היא אינה מיועדת לפריסה או להחלטות התקשרות.

להפעלה: `python3 app.py` ואז לפתוח http://127.0.0.1:8000. נדרש Python 3 בלבד. בסיס הנתונים נוצר מקומית; להחלפת מיקומו ניתן להגדיר `CONSULTANTS_DB`.

קובצי המקור אינם חלק מהפרויקט. תאריך הפרסום אינו תוקף המאגר או החוזה. לפני יבוא נתונים יש לבצע בדיקה אנושית, לשמור מקור לכל רשומה, להגדיר הרשאות ולבדוק את תחולת הנהלים עם גורמי העירייה.

## מנוע בדיקת מסלול התקשרות (טיוטה)
התיקייה `procurement/` כוללת מנוע כללים לפי תקנות העיריות (מכרזים): מסלול לפי שווי, פטורים, הגדלות, התקשרות המשך ובדיקת פיצול. ההסבר וההנחות שדורשות אישור נמצאים ב-`documentation/procurement-engine-he.md`. בדיקות: `python3 -m unittest discover -s tests -t .`

# טיוטת מיפוי תחומי מקור לקטגוריות

הקבצים הם הצעות לבדיקה אנושית, ולא סיווג מאושר או רשמי. נקודת המוצא היא
126 רשומות `registry_fields` משמונה מאגרים, שיוצאו מהמסד החי ב־13.11.2026
בקריאה בלבד. כל 126 זוגות מאגר ותחום תאמו להצעה הקודמת שנגזרה מקובצי
החילוץ המקומיים. פרסומי העירייה שטרם נטענו למסד אינם כלולים.

- `proposed-mapping.csv`: שורה אחת לכל שיוך מוצע, עם מזהי התחום והמאגר. כל
  שורה מסומנת ״מוצע - לא נבדק״. ייתכנו כמה שורות לאותו תחום.
- `unmapped.csv`: תחומים שאין להם הצעת שיוך וזקוקים לבדיקה.
- `field-cleanup.csv`: הצעת איחוד לשתי רשומות מקור שונות שההבדל ביניהן הוא
  שגיאת חילוץ. ההצעה משמרת את שני המזהים ואת שני נוסחי המקור; רק המזהה
  המוצע להשארה מופיע בטבלת השיוכים.

האיחוד טרם בוצע. לפניו יש לבדוק את המסמכים, את כל ההפניות לתחומים ואת
התנגשויות הייחודיות האפשריות בין רישומי ספקים, ולתכנן כיצד לשמר את המקור
וההיסטוריה. **אין להחיל מיפוי זה לפני ניקוי הנתונים המבוקר או התאמתו למצב
הנתונים בפועל.** אין למחוק או למזג רשומות אוטומטית על סמך הדמיון בלבד.

יש להשוות כל הצעה למסמך המקור, ובפרט לבדוק תחומים משולבים וטקסט משובש.
ההצעות הראשוניות נגזרו ממילות מפתח, ולכן ייתכנו שיוכים חסרים או שגויים;
גם שורה ללא הערת חריגה מחייבת בדיקה. סימון החריגות אינו מזהה את כולן.
המודל הקיים מאפשר קטגוריה אחת לתחום; טבלת שיוך לרבים נמצאת בטיוטת מיגרציה
נפרדת, ועדכון האתר לתמיכה בה עדיין נדרש. יש לשמר את נוסח המקור ואין להסיק
מהמיפוי זכאות להתקשרות או תוקף חוזה.

קבצים אלה אינם מיגרציה ואינם מאכלסים את המסד. לאחר בדיקה אנושית יש להכין
מיגרציה ובדיקות, לבדוק שוב את הנתונים ומספר גרסת המיגרציה, ולא לדרוס שיוך
קיים. החלה על המסד החי מחייבת אישור Menash.

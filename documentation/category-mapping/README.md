# טיוטת מיפוי תחומי מקור לקטגוריות

הקובץ `proposed-mapping.csv` הוא הצעה אוטומטית לבדיקה אנושית, ולא סיווג
מאושר או רשמי. כל שורה נושאת את מזהה תחום המקור ומזהה המאגר כפי שיוצאו
מ־`registry_fields` במסד החי ב־13.11.2026 בקריאה בלבד. נמצאו 126 רשומות
ייחודיות בשמונה מאגרים. כל 126 זוגות מאגר ותחום תואמים להצעה הקודמת שנגזרה
מקובצי החילוץ המקומיים; זיהוי הרשומות במיפוי החדש מבוסס על מזהי המסד.
היקף זה אינו כולל את שאר פרסומי העירייה שטרם נטענו למסד.

המיפוי מציע קבוצות מקצועיות ותתי־קטגוריות במקום העתקת שם המקור. כל שורה
עשויה להציע כמה שיוכים. תחום כללי שלא ניתן לסווג על סמך נוסחו נותר ללא שיוך.
זוהי הצעה שנגזרה ממילות מפתח, ולכן ייתכנו שיוכים חסרים או שגויים; גם שורה
ללא הערת חריגה מחייבת בדיקה. כל שורה נשארת במצב ״מוצע - לא נבדק״.

יש להשוות כל שיוך למסמך המקור, ובפרט לבדוק תחומים משולבים, ביטויים משובשים
וסוגריים הפוכים. סימון החריגות מסייע לבדיקה אך אינו מזהה את כולן. המודל
הקיים מאפשר קטגוריה אחת לתחום; טבלת שיוך לרבים נמצאת בטיוטת מיגרציה נפרדת,
ועדכון האתר לתמיכה בה עדיין נדרש. יש לשמר את נוסח המקור ואין להסיק מהמיפוי
זכאות להתקשרות או תוקף חוזה.

קובץ זה אינו מיגרציה ואינו מאכלס את המסד. לאחר בדיקה אנושית יש להכין מיגרציה
ובדיקות, לבדוק שוב את הנתונים ומספר גרסת המיגרציה, ולא לדרוס שיוך קיים.
החלה על המסד החי מחייבת אישור Menash.

# טיוטת מיפוי תחומים לקטגוריות

הקובץ `proposed-mapping.csv` מציע חלוקה ראשונית לבדיקה אנושית. כל השורות מסומנות
״מוצע - לא נבדק״. שמות הקטגוריות הם הצעה, ואינם מוצגים כסיווג רשמי של העירייה.
תת־הקטגוריה המוצעת משמרת את נוסח תחום המקור; היא אינה מאשרת שהחילוץ מדויק.

הרשימה נגזרה משני קובצי החילוץ המקומיים של הפרסומים, ולא מקריאה למסד החי.
לכן ייתכנו תחומים שנוספו, השתנו או חסרים במסד. היא כוללת רק זוגות מאגר ותחום
שנמצאו בקבצים; אין לכלול פרטי ספקים בקובץ. שדות שהכילו ` / ` פוצלו באותו אופן
שבו מיגרציית העתקת הנתונים פיצלה אותם. פסיקים לא פוצלו אוטומטית.

בעת הבדיקה יש להשוות למסמך המקור, לוודא שהקטגוריה ותת־הקטגוריה מתאימות,
ולהחליט בנוגע לטקסט משובש ולשדות הכוללים כמה תחומים. סיווג של תחום משולב
לקטגוריה אחת עלול להשמיט תוצאות: המבנה הקיים מאפשר קטגוריה אחת לתחום מקור.
סימון חריגה אינו בהכרח מלא, וגם שורה ללא הערה דורשת בדיקה. יש לשמר נוסח מקור
ואין להסיק מהשיוך זכאות להתקשרות או תוקף חוזה.

הקובץ נועד לדיון בלבד ואינו מיגרציה. לאחר גיבוש המיפוי יש להכין מיגרציה ובדיקות,
לבדוק את מספר הגרסה העדכני ואת תחומי המסד לפני החלה, ולא לדרוס שיוך שכבר נקבע.
החלה על המסד החי רק באישור Menash.

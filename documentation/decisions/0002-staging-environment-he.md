# סביבת בדיקה נפרדת ב-Supabase

תאריך: 13.11.2026. מצב: התקבלה.

## הקשר

יש היום פרויקט Supabase אחד, החי. כל שינוי במסד נבדק לראשונה מול נתונים אמיתיים.

## ההחלטה

ייפתח פרויקט Supabase שני כסביבת בדיקה, עם נתוני דמה בלבד. לריפו יתווסף `supabase/config.toml`, ופיתוח מקומי ייעשה מול Supabase מקומי.

## השלכות

מיגרציה ופונקציה מוחלות קודם בסביבת הבדיקה. צריך לוודא שהתוכנית הנוכחית ב-Supabase מאפשרת פרויקט נוסף בלי תשלום. אין נתונים אמיתיים בסביבת הבדיקה.

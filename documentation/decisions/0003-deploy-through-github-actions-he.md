# פריסה דרך GitHub Actions עם אישור

תאריך: 13.11.2026. מצב: התקבלה.

## הקשר

מיגרציות מוחלות היום ידנית, ותוצר האתר (`docs/`) שמור בריפו. אין תיעוד אוטומטי של מה הוחל ומתי.

## ההחלטה

שני תהליכי פריסה ב-GitHub Actions: אחד לאתר ואחד ל-Supabase (מיגרציות ופונקציות). התהליך של הסביבה החיה עוצר ומחכה לאישור של בעל המוצר בלחיצה.

## השלכות

אחרי ההקמה, החלה על המסד החי נעשית רק דרך התהליך הזה. תיקיית `docs/` יוצאת מהריפו. הסודות מוגדרים ב-GitHub פעם אחת ומתועדים ב-`.env.example` בלי ערכים.

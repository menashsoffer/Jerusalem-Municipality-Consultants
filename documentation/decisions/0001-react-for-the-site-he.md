# האתר עובר ל-React

תאריך: 13.11.2026. מצב: התקבלה.

## הקשר

האתר נבנה היום בבניית DOM ידנית, בלי קומפוננטות ובלי ניתוב. זה מתאים למסך חיפוש אחד, ולא למסכי ניהול, טפסים ותהליכי אישור.

## ההחלטה

האתר ייכתב ב-React עם TypeScript קפדני ו-Vite. הגישה לנתונים תעבור ללקוח הרשמי `supabase-js` עם הטיפוסים שנוצרים מהמיגרציות. רכיבים משותפים יישבו ב-`web/src/ui/`, וכל אזור מסך בתיקייה משלו ב-`web/src/features/`. אימות קלט ייעשה ב-Zod, באותן סכמות שמשמשות את ה-Edge Functions.

## השלכות

ההעברה הדרגתית, מסך אחרי מסך, לפני בניית מסכי הניהול. ספריית רכיבים חיצונית תתווסף רק בהחלטה נפרדת. כל כללי הגודל והאבטחה הקיימים חלים גם על קומפוננטות.
